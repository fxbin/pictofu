# SEO Page Map v0.1

## Strategy

PicTofu uses a memorable brand domain and search-intent routes. The brand is not the keyword container; routes, metadata, copy, internal links and actual preset behavior satisfy search intent.

## Page contract

Every search route must include:

1. Unique title and description.
2. One clear H1 matching the user’s intent naturally.
3. A concise explanation of what the page does.
4. Primary CTA that launches the matching preset.
5. Real preset differences in layout/filter/frame defaults.
6. Useful supporting content: how it works, relevant tips, privacy note, FAQ where appropriate.
7. Related-experience internal links.
8. Canonical URL.
9. No requirement for camera permission to read/index primary content.

## Anti-thin-page rule

Do not create a route only by replacing a keyword in otherwise identical copy. New routes are justified by a meaningful difference in user intent and/or default booth experience.

## Internal linking model

Home → flagship intent routes → related style/occasion routes → booth.

Result/edit screens may link back to the preset used, but should not become indexable duplicate landing pages.

## Technical checklist

- metadata per route
- canonical per route
- sitemap inclusion for indexable routes
- robots allows public landing routes
- noindex for transient session/result states if separate URLs are introduced
- server-rendered primary copy
- shareable Open Graph metadata

## Validation cadence

Day 7: indexing/crawl health.
Day 14: impressions/query discovery.
Day 30: impressions + clicks + product completion by landing page.
