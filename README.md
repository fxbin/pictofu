# PicToFu

PicToFu is a mobile-first, privacy-first web photobooth for creating cute photo strips directly in the browser.

## Current phase

MVP foundation and 72-hour launch experiment.

## Product principle

**No install. Open. Pose. Download.**

The first release focuses on the shortest useful loop:

`Landing → Start Booth → Camera → Capture → Style → Download / Share`

Development workflow and product decisions are tracked in-repository under `docs/` and `.vidt/`.
