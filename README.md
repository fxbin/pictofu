# PicToFu

PicToFu is a mobile-first, privacy-first web photobooth for creating cute photo strips directly in the browser.

## Current phase

Production validation and acquisition experiment.

Feature breadth is temporarily frozen while the current P0 validation debt is closed. The priority is to stabilize the existing Booth, prove the real-device flow, measure acquisition/share behavior, and only then expand Frames, Filters, Presets, or heavier product capabilities.

Tracking:
- #139 — release boundary + executable state/privacy contracts
- #102 — iOS Safari / Android Chrome real-device acceptance
- #116 / #120 — acquisition + Search Console evidence

## Product principle

**No install. Open. Pose. Download.**

The useful loop is:

`Landing → Start Booth → Camera → Capture → Review/Edit → Style → Download / Share`

Development workflow and product decisions are tracked in-repository under `docs/`, `.vidt/`, and GitHub Issues.
